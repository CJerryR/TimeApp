## 未完成 / 后续

- **安装器与发布包**：`package.json` 目前只有开发、启动、构建、类型检查和 smoke 命令，没有 electron-builder、签名、安装器或自动更新配置。
- **真实外部连接器**：飞书、邮箱、微信、ICS / CalDAV 当前在接入页标记为“规划中”；现阶段只有线索数据模型、来源状态与确认队列界面。
- **完整英文界面**：设置中保留语言字段，但当前界面以中文为主，英文文案尚未完整实现。
- **发布前重新验证**：若干当前运行时文件与有效批次报告中记录的源码哈希不同。发布候选确定后，需要重新执行 typecheck、build 和完整 smoke，并更新有效基线。
- **验证产物取舍**：`desktop/verification/` 已由 Git 忽略，不上传历史 JSON、日志或原始截图；README 仅引用复制到 `docs/assets/` 的精选脱敏截图。

## 已知限制

- **透明窗口截图边界**：smoke 模式故意使用不透明桌宠窗口和深色背景，`capturePage()` 得到的是已经合成的 PNG。它能验证角色渲染、尺寸、位置和唯一性，不能证明生产透明窗口的桌面透出效果。
- **自动测试边界**：当前没有单元测试或独立集成测试框架。Electron smoke 覆盖大量运行时、持久化和视觉契约，但不覆盖安装器、代码签名、自动更新、真实外部服务连接或外部桌面 compositor 的逐像素 alpha 捕获。
- **npm 镜像警告**：当前 `.npmrc` 使用 `electron_mirror` 与 `electron_builder_binaries_mirror`；npm 已提示这些旧式配置将在下一 major 停止支持。现有有效批次未因此失败。
- **Windows 网络通知噪声**：Electron smoke 曾输出 `WSALookupServiceBegin failed with: 10108`，但进程退出码为 0，断言未受影响。
- **最小生产窗口**：正常主窗口最小尺寸为 920×640；420×900 是 smoke 响应式验证模式，不代表当前生产窗口允许缩到 420px 宽。
- **像素资产可复现性**：现有 24 帧可通过文件哈希、尺寸与 alpha 统计核验，但工作区没有完整生成脚本与全部精确参数，不能宣称可从零位级复现。

## 回退 / 迁移说明

- Live2D / Layered2D 迁移前的角色目录、运行时和关键源码备份保存在活动仓库之外的工作区归档中，当前 GitHub 源码不会加载这些内容。
- 回退应先保存当前前向状态，再恢复旧源码、旧运行时与旧角色目录，最后重新执行 build 和 smoke；当前尚未执行回退。
- 迁移归档不包含用户 `timemate.sqlite`。回退前必须由用户单独备份数据库；不得通过删除数据库来解决角色 ID 不兼容。
- 如果数据库已经保存 `ruohan-pixel-v1`，回退到旧角色系统后需要恢复迁移前数据库备份，或在恢复后的设置中重新选择实际存在的角色。
- JSON 导入会整体替换当前数据。任何迁移或回退操作前，都应先导出完整 JSON 备份并核对其中是否包含个人任务、日历、记忆和聊天内容。
